# Contributor Covenant Code of Conduct

## Our pledge

We pledge to make participation in this project a harassment-free experience for everyone,
regardless of age, body size, disability, ethnicity, sex characteristics, gender identity and
expression, experience level, education, socioeconomic status, nationality, personal appearance,
race, caste, color, religion, or sexual identity and orientation.

## Expected behavior

Be respectful, give and accept constructive feedback, focus on what is best for the community, and
show empathy toward others. Unacceptable behavior includes harassment, discriminatory language,
personal attacks, unwanted sexual attention, threats, doxxing, and publishing private information
without permission.

## Enforcement

Report unacceptable behavior privately to the repository maintainers. Maintainers may remove,
edit, or reject comments, commits, code, issues, and other contributions that violate this code,
and may temporarily or permanently ban contributors for inappropriate behavior. Reports will be
reviewed as promptly and fairly as project capacity permits, with respect for reporter privacy.

## Scope

This code applies in project spaces and when someone officially represents the project in public.
